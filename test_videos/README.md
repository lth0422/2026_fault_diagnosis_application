# test_videos/

오디오 사용성 검증(D1 멀티모달)용 슬로모션 테스트 영상 보관 폴더.
영상/오디오 파일(`*.mp4/mov/wav` 등)은 `.gitignore`로 git 추적 제외(용량·로컬 전용).

## 넣어줄 것 (권장)
- 서로 다른 결함 클래스 영상 2~4개 (예: 정상 1, IR 1, OR 1, B 1) — 스펙트럼 비교용.
- 원본 그대로(재인코딩 X). 파일명에 결함라벨·RPM 포함하면 좋음 (예: `IR_1200rpm.mov`).

## 확인 목적
1. 오디오 트랙 존재/샘플레이트/코덱 (ffprobe)
2. 오디오 길이 vs 영상 길이 → 실시간 vs time-stretch 판정
3. 오디오 FFT → 회전주파수/베어링 결함주파수가 실제 대역에 있는가
