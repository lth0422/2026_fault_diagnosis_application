# 오디오 모달리티 실현성 분석 (D1 멀티모달)

슬로모션 영상에 딸린 **오디오가 베어링 결함 진단에 쓸 수 있는가**를 실제 파일로 검증한 결과.
→ **결론: 쓸 수 있다. 외륜(OR) 결함 서명(BPFO+고조파)이 오디오에 명확히 존재하며, stretch 복원 후 이론값과 일치.**

## 대상 파일
- `test_videos/1217_6204_1200_OR_F_3.mp4` (gitignore, 로컬 전용)
- 라벨 해석: 베어링 **6204**, **1200 rpm**(공칭), **OR(외륜)** 결함.
- 스트림: 영상 1920×1080 **59.94 fps** 40s / 오디오 **AAC 44100 Hz 스테레오 102 kb/s**.

## 핵심 발견
1. **Stretch 배수 = 240 / 59.94 = 4.004×** — 240fps로 촬영→59.94fps로 export된 슬로모션.
   오디오도 영상과 함께 4배 늘어남(주파수는 1/4로 이동).
2. **포락선(envelope) 분석**(2–8kHz 공진대역 밴드패스 → Hilbert 포락 → FFT):
   - 기본파 **14.87 Hz** + 정수배 고조파(29.74 / 44.62 / 59.49 / 74.36 Hz) = 전형적 베어링 결함 변조.
3. **실시간 복원**: 14.87 × 4.004 = **59.5 Hz** ≈ 6204 **BPFO 이론값 61.0 Hz**(1200rpm).
   - 역산 실제 회전속도 ≈ **1171 rpm** (모터가 1200보다 약간 낮음 — 정상 범위).
4. 6204 이론 결함주파수(1200rpm=20Hz): FTF 7.6 / BSF 39.8 / **BPFO 61.0** / BPFI 99.0 Hz.

## 의미 (왜 중요한가)
- ✅ **오디오는 fps 한계와 무관**하게 결함주파수를 담는다. 240fps 영상은 Nyquist 120Hz라 BPFO(61Hz)의
  고조파(122Hz+)를 못 잡지만, **오디오는 BPFO + 다수 고조파를 온전히 담음**(복원 후 59.5·119·178·238·298Hz).
- ✅ **이미 취득한 데이터**에 들어 있음 → 추가 하드웨어·재촬영 없이 오디오만 추출하면 됨.
- ✅ D1(카메라+마이크 멀티모달)이 **실현 가능**함을 실측으로 확인. 우리 최대 약점(fps)을 정면 해결.

## 한계·주의
- 오디오가 **AAC 손실압축**(102kb/s)이지만 결함 서명은 살아남음. 향후엔 무압축/고비트레이트 권장.
- **stretch 복원 필요**: 분석 시 주파수축 × (촬영fps/exportfps). export fps가 파일마다 다를 수 있어 파일별 확인.
- 지금은 **OR 1개 파일**만 검증. 완전 검증엔 정상/IR/B도 확인 필요:
  - 정상 → BPFO 서명 없어야, IR → BPFI(99Hz), B → BSF(40Hz)·2×BSF 나와야.
- 실시간 유효대역: 44.1kHz를 4배 복원 시 이론상 여유. 실제 마이크·거리·배경소음 영향은 조건별 평가 필요.
