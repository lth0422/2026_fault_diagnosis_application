# 앱·논문 강화 아이디어 (다방면 브레인스토밍)

이미 정한 3대 델타([paper_concept.md](paper_concept.md) 1-A: ①누수 재평가 ②그림4 확장 ③다조건 강건성) **외에**,
앱과 논문을 강화할 수 있는 아이디어를 전 방면으로 모은다. 각 항목: **강화대상 / 효과 / 난이도 / 우리 발견과의 연결**.

> 표기: 🅰=앱 강화, 🅿=논문 강화, ⭐=우선 추천. 난이도 하/중/상.

---

## ⭐ 우선 추천 TOP 6 (효과 대비 실현성 높음)

| 아이디어 | 대상 | 왜 강력한가 |
|----------|------|-------------|
| **1. 카메라+마이크 멀티모달** | 🅰🅿 | 스마트폰 마이크(음향, 고주파)로 **240fps fps 한계를 보완** — 우리 최대 약점을 스마트폰 고유 자산으로 메움. novelty 큼 |
| **2. XAI + 결함주파수 오버레이** | 🅰🅿 | 모델이 어느 주파수/구간을 보는지 시각화 + FFT에 BPFO/BPFI 이론선 표시. 포스터 그림4를 앱 안으로 |
| **3. 불확실성 정량화 + 방어 UX** | 🅰🅿 | 신뢰도 낮으면 "재촬영" 유도 → **H 쏠림 문제 완화** + 정직한 보고(C4 불확도와 연결) |
| **4. 실시간 촬영 품질 가이드** | 🅰 | 조명·거리·각도·흔들림·마커검출률을 촬영 **전에** 실시간 체크 → 강건성 약점을 UX로 완화 |
| **5. 공개 스마트폰 베어링 영상 데이터셋** | 🅿 | 다조건·복수베어링 데이터 공개 = 커뮤니티 기여, 저널에서 강한 가점 |
| **6. 입력표현·모델 벤치마크** | 🅿 | 포스터의 빈약한 ANN 비교를 대체(1D-ResNet/TCN/Transformer, 스펙트로그램 입력 등) |

## A. 모델 / 학습 방법

- **A1. 불확실성 정량화(Uncertainty-aware)** 🅰🅿⭐ [중] — MC-Dropout / Deep Ensemble / Evidential DL로 예측 신뢰구간. 앱은 저신뢰 시 진단 보류·재촬영. 논문은 신뢰도 보정(calibration)까지. → H 쏠림·정직한 성능과 직결.
- **A2. 결함 심각도(severity) 추정** 🅰🅿 [중] — 분류(B/H/IR/OR)를 넘어 crack 깊이(0.5/1.0/1.5mm)를 회귀/서열분류. 새로운 task = 논문 확장. 앱은 "결함 진행 정도" 표시.
- **A3. Physics-informed 모델** 🅿⭐ [상] — BPFO/BPFI 주파수를 손실/attention에 주입(order-domain). **저주파에서도 판별력 확보 시도** → fps 한계 정면 대응, 델타 ②와 시너지.
- **A4. 1D→2D 입력표현 비교** 🅿 [하] — DisplacementZ를 스펙트로그램/order-spectrum/recurrence plot으로 변환 후 2D-CNN. 영상 진단 문헌 다수가 이 방식(그레이스케일 인코딩). 입력표현 ablation.
- **A5. 최신 경량 아키텍처 벤치마크** 🅰🅿⭐ [중] — WDCNN vs 1D-ResNet/Inception1D/TCN/소형 Time-series Transformer. 온디바이스 크기·지연 trade-off 포함. 포스터 ANN 비교를 제대로 대체.
- **A6. 자기지도/대조학습 사전학습** 🅿 [상] — 라벨 없는 신호로 사전학습 → 소규모 라벨 대응(D6 few-shot과 연결).
- **A7. 도메인적응/교차모달 전이** 🅿 [상] — CWRU 가속도 → 우리 영상 변위로 전이(cross-modality). 일반화·소규모 데이터 동시 대응.
- **A8. 멀티태스크 학습** 🅰🅿 [중] — 결함유형 + RPM 추정 + 검출품질을 동시 출력. 앱 정보 풍부화 + 정규화 효과.

## B. 입력 신호 / 특징

- **B1. X변위 동시 활용(2채널 궤도)** 🅰🅿⭐ [중] — 현재 Z만 사용. X+Z 궤도(orbit) 분석은 불평형/정렬불량/베어링 결함 구분에 유리. 정보량↑.
- **B2. 다점(multi-marker/multi-point) 추적** 🅿 [중] — 여러 지점 변위 → 방향·위상 정보. 향후 마커리스 full-field로 확장 여지.
- **B3. Order tracking(회전 정규화)** 🅰🅿 [중] — RPM으로 정규화 → 가변속도 대응(RESS 문헌). 앱의 RPM 입력/추정 활용. 델타 ③(다조건)과 연결.
- **B4. Envelope/포락 스펙트럼 특징** 🅿 [하] — 결함주파수 강조 특징을 명시적으로 추출·비교.

## C. 앱 기능 / UX / XAI

- **C1. XAI 시각화(Grad-CAM/attention)** 🅰🅿⭐ [중] — 모델이 신호의 어느 시간구간/주파수를 근거로 판단했는지 오버레이. 진단 신뢰성·설명가능성(논문) + 사용자 이해(앱).
- **C2. 결함주파수 이론선 오버레이** 🅰⭐ [하] — 앱 FFT 화면에 BPFO/BPFI/BSF 이론선 표시(RPM·베어링 제원 입력 기반). 포스터 그림4의 교육/근거 버전.
- **C3. 실시간 촬영 품질 가이드** 🅰⭐ [중] — 촬영 전/중 조명·거리·각도·흔들림·마커검출률을 실시간 점수화 → 좋은 데이터 유도. 강건성 약점을 UX로 흡수. 논문엔 "데이터 품질 관리 프로토콜"로.
- **C4. 신뢰도·불확도 표시 + 방어 로직** 🅰⭐ [하] — 검출 0/저품질 시 진단 보류(현재 H 쏠림 방어). A1과 결합.
- **C5. 시계열 모니터링/트렌드 대시보드** 🅰🅿 [중] — 반복 측정 저장 → 결함확률·zStdDev·검출률의 시간 추세 → 예지보전(트렌딩). 현장 실용성↑.
- **C6. 자동 리포트 생성/공유** 🅰 [하] — 진단 결과+불확도+촬영조건 메타데이터+CSV를 PDF 리포트로. 현장 문서화.
- **C7. 온디바이스 개인화(선택)** 🅰 [상] — 특정 기계에 소량 fine-tune. 실현성 낮으나 차별점.

## D. 센서 융합 (스마트폰 고유 강점)

- **D1. 카메라 + 마이크(음향) 멀티모달** 🅰🅿⭐ [중] — 마이크로 음향(고주파) 동시 취득 → **영상(저주파 변위)의 fps 한계를 음향이 보완.** 스마트폰 하나로 이종 센서 융합 = 강한 novelty. 우리 최대 약점을 정면 해결.
- **D2. 카메라 + IMU(자이로/가속도)** 🅰 [중] — 자이로로 흔들림/각도 보정(Yu 2021), 내장 가속도계로 보조 검증. 핸드헬드 강건성.
- **D3. 롤링셔터 활용** 🅿 [상] — SURVISHNO처럼 rolling shutter로 프레임레이트 초과 주파수 정보 추출 → **고RPM 대응 가능성**(fps 천장 우회). 실험적이지만 임팩트 큼.

## E. 평가 / 과학적 엄밀성

- **E1. 신뢰도 보정(Calibration)** 🅿 [하] — ECE·reliability diagram으로 예측확률이 실제 정확도와 맞는지. 정직한 평가 축 강화.
- **E2. OOD/novelty 검출** 🅰🅿 [중] — 학습 안 한 상태(미지 결함/비대상) 거부 → 현장 오진 방지.
- **E3. 교차 데이터셋 검증** 🅿 [중] — CWRU/Paderborn에 우리 파이프라인·평가 프로토콜 적용 → 일반화·방법론 타당성.
- **E4. 요소별 Ablation** 🅿 [하] — 마커/HSV/리샘플링/윈도우 크기/중첩의 기여도 분해.
- **E5. 재현성 패키지 공개** 🅿 [하] — 코드·누수없는 split·평가 스크립트 공개. 신뢰성↑.

## F. 데이터셋

- **F1. 공개 스마트폰 베어링 영상 데이터셋** 🅿⭐ [상] — 다조건(RPM·조명·거리·각도·기기)·복수 베어링. 커뮤니티 기여 = 저널 강한 가점. bearing-wise 평가 가능화(델타 ①과 직결).
- **F2. 물리기반 합성/증강** 🅿 [중] — 결함 임펄스 모델로 신호 증강 → 소규모 보강.

## G. 배포 / 시스템

- **G1. 모델 양자화·프루닝** 🅰🅿 [중] — 지연·크기 최적화, 저사양폰 대응. "온디바이스 효율" 정량 분석 = 논문 소재.
- **G2. iOS/Android 결과 일관성 보장** 🅰 [중] — 현재 IR→OR 오분류 원인 규명·수정 → 크로스플랫폼 신뢰성(현행 미결 이슈).
- **G3. 지연·전력·발열 프로파일링** 🅿 [하] — 현장 연속 사용성 평가.

## 조합 시나리오 (앱↔논문 시너지)

- **"믿을 수 있는 현장 진단기"**: A1(불확도) + C3(품질가이드) + C4(방어) + E1(보정) → 앱은 신뢰도 높은 UX, 논문은 정직·강건 성능.
- **"fps 한계 정면돌파"**: D1(음향 융합) + A3(physics-informed) + B3(order tracking) → 우리 최대 약점을 다각도로 해결, novelty 집중.
- **"설명가능한 진단"**: C1(XAI) + C2(결함주파수 오버레이) + A5(벤치마크) → 근거 있는 진단, 포스터 대비 확실한 심화.
- **"커뮤니티 기여형"**: F1(공개 데이터셋) + E3(교차검증) + E5(재현성) → 방법론·데이터 기여로 임팩트.
